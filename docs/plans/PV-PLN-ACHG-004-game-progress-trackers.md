## Product and ownership rules

- Access through the Hub, a game, or a specific achievement. Achievement entry points prefill the same universal creation/import form with that game's achievement. The user can change or clear the link. Changing the game clears an incompatible link.
- Linking and unlinking must retain the tracker identity, item IDs, account data, notes and observations. Links are local organization metadata and do not award provider achievements or points.
- Definitions describe what can be tracked. Account/profile-scoped observations describe what a source saw. Manual progress, notes and source observations remain separate.
- Unknown, available, locked and completed remain distinct. A missing field or unsupported parser is unknown, never an invented zero.
- Availability is separate from completion. Fabrication, placement, upgrading, discovery, pickup and restoration are different milestones.
- Save adapters read stable copies. They never alter game files, game saves or provider unlock state.
- New adapters require validated identities and before/after evidence for each progress field. Resource metadata alone is not evidence of personal completion.
